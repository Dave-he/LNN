
# LNN iOS 应用 - 快速开始指南

## 项目概述

这是一个用于在 iPad/iPhone 上运行液态神经网络（Liquid Neural Network，LNN）的 iOS 应用，具体实现了闭式连续时间网络（Closed-form Continuous-time，CfC）用于时间序列预测。

## 功能特点

- ✅ 实时模拟 - 观察 LNN 预测正弦波模式
- ✅ 多种数据生成器 - 测试不同的时间序列模式
- ✅ 交互式控制 - 开始/停止、重置、切换数据类型
- ✅ 精美图表 - 可视化真实值与预测值对比
- ✅ 轻量级实现 - 纯 Swift，无外部依赖

## 如何在 Xcode 中运行

### 方法一：创建新的 Xcode 项目（推荐）

1. 打开 **Xcode**
2. 点击 **Create a new Xcode project**
3. 选择 **iOS** -&gt; **App**
4. 填写项目信息：
   - Product Name: `LNNDemo`
   - Interface: `SwiftUI`
   - Language: `Swift`
5. 将 `LNNDemo/` 文件夹下的所有文件复制到你的新项目中
6. 替换或添加相应的文件
7. 选择你的 iPad/iPhone 模拟器或真机
8. 按 **Cmd + R** 运行

### 方法二：使用启动脚本

在终端中运行：

```bash
cd /path/to/LNN/ios/LNNDemo
./start_xcode.sh
```

## 液态神经网络简介

液态神经网络（LNN）是一类专为序列数据和时间序列预测设计的神经网络。主要特点：

- **连续时间动力学** - 连续地建模时间演化
- **闭式解（CfC）** - 避免昂贵的 ODE 求解器
- **紧凑尺寸** - 比传统 RNN/LSTM 参数更少
- **可解释性** - 更清晰的内部动力学理解

## 常见问题

**Q: 应用支持哪些设备？**
A: 支持 iPhone 和 iPad，推荐在 iPad 上获得更好的体验。

**Q: 如何添加自己训练的模型？**
A: 需要将 PyTorch 训练的权重导出，然后在 `CfCModel.swift` 中加载。

**Q: 可以在真机上运行吗？**
A: 可以，需要配置 Apple Developer 账号并签名。

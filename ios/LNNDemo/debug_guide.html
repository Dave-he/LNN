🍎 LNN iPad 真机调试指南

Liquid Neural Network - 完整的部署和调试流程

0% 完成
1 检查设备连接
1.1 连接 iPad

使用 USB-C 或 Lightning 线缆将 iPad 连接到 Mac

1.2 在 iPad 上信任电脑

在 iPad 弹出的提示中点击「信任」，然后输入设备密码

1.3 验证连接

在 Mac 上打开「访达」，确认左侧能看到你的 iPad

💡 提示：如果连接不稳定，尝试更换 USB 线或使用 Mac 上的直接 USB-C 接口
iPad 已通过 USB 线连接到 Mac
iPad 上已点击「信任」此电脑
在「访达」中能看到 iPad
2 配置 Xcode 项目
2.1 打开项目

确保 LNNDemo 项目已在 Xcode 中打开

2.2 选择项目设置

在 Xcode 左侧导航栏最顶部，点击蓝色的 LNNDemo 项目图标

2.3 配置签名

在 TARGETS -> LNNDemo -> Signing & Capabilities 中：

  • Team：选择你的 Apple ID 个人团队
  • Bundle Identifier：改为 com.你的名字.LNNDemo
⚠️ 重要：Bundle Identifier 必须是全球唯一的，不能使用示例的 com.example.LNNDemo
Team 已选择（显示你的名字或 Personal Team）
Bundle Identifier 已修改为唯一值
Signing 显示 ✅ 无错误
3 配置 iPad 开发者模式
3.1 打开设置

在 iPad 上打开「设置」应用

3.2 进入隐私与安全性

滚动到最底部，找到「隐私与安全性」

3.3 启用开发者模式

找到「开发者模式」选项，打开开关，按照提示重启 iPad

💡 提示：开发者模式重启后，记得再次确认开关保持打开状态
iPad 已升级到 iPadOS 16.0+
开发者模式已开启
iPad 已重启完成
4 在 Xcode 中选择设备
4.1 找到设备选择器

在 Xcode 窗口顶部工具栏，找到设备选择器（显示「My Mac」或模拟器名称的地方）

4.2 选择你的 iPad

点击下拉菜单，选择你的 iPad（会显示 iPad 的名称）

4.3 配对设备（如需要）

如果设备显示「未配对」，在 Xcode 中选择 Window -> Devices and Simulators 进行配对

在 Xcode 设备选择器中能看到 iPad
已选择 iPad 作为目标设备
5 运行应用！
5.1 运行项目

点击 Xcode 左上角的播放按钮（▶️），或按快捷键 Cmd + R

5.2 等待编译和安装

Xcode 会编译项目，然后将应用安装到 iPad 上

5.3 信任应用（首次安装）

在 iPad 上：设置 -> 通用 -> VPN 与设备管理 -> 信任你的 Apple ID

✅ 成功！应用现在应该在 iPad 上运行了！

已在 iPad 上信任应用

调试常用快捷键

  • Cmd + R - 运行应用
  • Cmd + . - 停止运行
  • Cmd + 8 - 显示断点导航器
  • F6 - 单步跳过
  • F7 - 单步进入
  • F8 - 单步跳出

添加断点

在代码行号左侧点击，会出现蓝色箭头标记断点。运行时会在断点处暂停。

问题 1：No signing certificate

解决：检查 Apple ID 是否已添加到 Xcode，Team 是否已选择

问题 2：Bundle ID 已被使用

解决：修改 Bundle Identifier，使它更独特，包含你的名字

问题 3：设备不显示

解决：重新插拔 USB 线，检查 iPad 解锁，确认信任设置

问题 4：应用闪退

解决：添加异常断点（Cmd+8，点击 +，Add Exception Breakpoint）

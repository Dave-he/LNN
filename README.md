# LNN (Liquid Neural Networks) 最新进展汇总与研究

本项目是一个专注于**液态神经网络（Liquid Neural Networks, LNN）**最新开源进展与研究成果的汇总项目。

## 🎯 项目目的

- **每日追踪**：每天汇总并更新最新的 LNN 相关学术论文与开源项目。
- **研究分析**：对收集到的论文和代码进行深入的研究、解读和分析。
- **开源共享**：与开源社区共同分享 LNN 领域的前沿发展趋势，促进技术交流。

## 📁 目录结构

为了保持项目的整洁与可维护性，项目采用以下目录结构规划：

```text
LNN/
├── README.md          # 项目说明文档（本文件）
├── papers/            # 原始论文存放目录及每日/每周论文追踪汇总
│   └── daily/         # 每日最新论文追踪记录
├── projects/          # 各个 LNN 开源项目的深度分析报告与调研
├── analysis/          # 重点论文的深度解读、研究笔记和原理解析
├── docs/              # 学习笔记、翻译与通用技术汇总文档
├── scripts/           # 用于自动化抓取论文、更新汇总的工具脚本
└── src/               # 源代码目录，用于未来编写 LNN 相关的实验代码或复现模型
```

## 📚 目录详细说明

1. **`papers/`**
   - 存放从外部获取的原始文献（如 PDF）以及 `daily/` 子目录下的每日论文动态追踪。
2. **`projects/`**
   - 存放各个 LNN 开源项目的分析报告。针对 GitHub 上的前沿开源库进行架构拆解、代码导读与评测。
3. **`analysis/`**
   - 专门用于存放单篇或多篇重点论文的深度剖析与理论推导。
4. **`docs/`**
   - 存放项目基础文档、学习路径指南、术语表等。
5. **`scripts/`**
   - 预留用于编写自动化脚本（如调用 ArXiv API 自动获取每天包含 "Liquid Neural Network" 关键词的论文）。
6. **`src/`**
   - 预留用于编写 LNN 相关的实验代码或模型复现验证环境。

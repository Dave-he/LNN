# 液态神经网络优化策略

基于论文研究和实验分析，本项目提供了以下优化策略建议：

## 1. 模型架构优化策略

### 1.1 速度优先：CfC 变体
- **严格 CfC (Strict CfC)**: 最佳速度，适合需要高精度连续时间建模，但训练更严格连续时间更新
- **混合 CfC (Hybrid CfC)**: 结合 RNN 门控机制与连续时间，平衡速度与精度
- **CfC-DT**: 对不规则采样数据有更好的时间步支持

### 1.2 精度优先：LTC 变体
- **LTC (Liquid Time-Constant)**: 原始的，最准确的 ODE 求解
- **CT-LTC**: 连续时间 LTC，更适合长程依赖
- **LRC (Liquid Resistive-Capacitive)**: 引入生物合理性更好，振荡抑制效果好

### 1.3 长序列建模：Liquid-S4
- 结合 S4 的结构化状态空间与 LNN 的连续时间
- 特别适合超长序列任务

## 2. 训练优化策略

### 2.1 超参数建议
```python
# 基础配置
hidden_size: 32-128  # LNN 不需要特别大的隐藏层
num_layers: 1-2      # 通常 1 层足够
lr: 0.001-0.003    # 较小的学习率更稳定
batch_size: 32-128
```

### 2.2 正则化技术
- **梯度裁剪**: 防止梯度爆炸，建议值 1.0
- **学习率调度**: ReduceLROnPlateau 降低验证平台
- **早停**: 15-20 epoch 耐心值
- **初始化**: 合适的 tau 参数正向约束

### 2.3 优化器选择
- Adam 或 AdamW 最佳
- 学习率预热在训练初期很重要

## 3. 部署优化策略

### 3.1 边缘设备优化
1. **量化**
   - 8-bit 量化
   - 显著减少内存和计算

2. **简化版本
   - Euler-LTC-DT: 使用简单，特别适合 Jetson 等边缘设备
   - 使用 Euler 方法代替 RK4 求解器

3. **稀疏化**
   - 借鉴 AutoNCP 的稀疏连接
   - 神经元修剪

### 3.2 计算优化
1. 向量化所有操作
2. JIT 编译
3. 避免循环优化

## 4. 应用场景建议

### 4.1 时序预测
- 推荐: CfC > Hybrid CfC > Strict CfC

### 4.2 机器人控制
- 推荐: LTC > CT-LTC

### 4.3 边缘实时处理
- 推荐: CfC-DT, Euler-LTC-DT

### 4.4 长序列/视频理解
- 推荐: Liquid-S4

## r306 增量：SDE-CfC 落地 (2026-09-21 闭环)
- 研读了 arXiv 2608.28702 (Stochastic Liquid Deformation Fields) 并把"SDE view of CfC"建议落地到 toy benchmark：`lnn/core/sde_cfc.py` (`SDECfCCell` + `SDECfCNetwork`) + `scripts/bench_sde_cfc.py` + `results/bench_sde_cfc_v2.json`。
- 100-epoch × 3-seed × 3-dataset × 5-cond sweep 结果为 **诚实负向-with-nuance**：fixed σ {0.05, 0.10, 0.20} 在 toy_sin / random_irr 上 Δ ∈ [0.0%, +0.3%] 全部中性；structured_irr Δ ∈ [-0.2%, -0.0%] 边际改善；**learnable σ 从 0.05 漂移到 0.72 (14×) 并 toy_sin +2.5% / structured +8.3%**（典型 gradient-over-regularization）。
- 评估时 noise 完全关闭、模型精确退化为 vanilla CfC (bit-exact)，验证了论文 §3.2 的精确极限声称。
- 失败原因分析：sigmoid gate squashes Gaussian noise → effective 正则化幅度近零；与 r192 input noise (σ=0.05 toy_sin -24%) 对照证明"加 noise 的位置决定一切"——unbounded input 加 noise 起 regularization，bounded pre-sigmoid gate 加 noise 饱和。
- 详见 `docs/reports/SDE_CfC_r306_2026-09-21.md`。

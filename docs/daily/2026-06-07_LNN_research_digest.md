## 今日深度研读

### 1. 集群信号：电池健康赛道的「同组双发」
- **DLNet** ([arXiv 待补], 2026-01-09) 与 **EntroLnn** ([arXiv 待补], 2026-01-08) 共享作者 Wei Li、Wei Zhang（及 EntroLnn 额外的 Qingyu Yan），并在相近时间窗内连发两篇 LNN 电池论文。
- DLNet 主打「双阶段蒸馏 + Pareto 引导压缩」——把高容量 LNN 教师模型压到边缘可部署的紧凑学生，主战场是边缘 SoH 估计。
- EntroLnn 走「熵引导在线轨迹精修」路径，扩展到 operando（即电池在原位工作状态下）容量衰减全轨迹的持续细化。
- **项目意义**：两篇构成「离线训练 + 在线更新」的完整链路，与 LNN 边缘部署的核心卖点（参数效率 + 适应性时间常数）天然契合。
- **可复现性**：仓库暂未发现，论文摘要中提到「compact and edge-deployable」，可作为 round 74 的备选 PRD 选题——若实现 19-神经元级 LNN 蒸馏版，在 Jetson Orin Nano 上的延迟将是说服性指标。

### 2. 与 round 73 (CfC vs DSS/S4/Mamba/GRU) 的延续信号
- round 73 bench 给出诚实负向：**3 epoch 预算下 GRU 在回归任务上击败 CfC/DSS/S4/Mamba**。今日 digest 中**未发现 24h 内新增的同主题论文**，但几个观察值得记录：
  - **EDSSM** ([Alexng2024/EDSSM](https://github.com/Alexng2024/EDSSM), 2026-06-01) 提出 Event-Driven State Space Model——本质是 `e^{AΔt}` 闭式连续时间线性动力学 + 事件门控更新。这与 DSS/S4 同属 SSM 谱系，但有「事件驱动稀疏更新」特性。下一步可作为 bench 候选对照组。
  - **FHRN** ([2025-12-04] Continuous-Time Homeostatic Dynamics) 把 fast-weights 重新进入机制写成 neural-ODE，与 CfC 同属连续时间家族但走 homeostatic 正则化路线。
  - **AEGIS** ([arXiv:2604.02149v1], 2026-04-02) 提出 Thermodynamic State Space Model——这是 LFM2.5 架构思路在零日攻击检测任务上的平行演化，值得在概念层面对齐。
- **建议**：round 74 候选 PRD = 「EDSSM 接入 bench_suite 36-cell sweep」，与 round 73 同协议，验证事件驱动稀疏更新是否在低预算下反超密集 SSM。

### 4. 复现 / 警戒信号：cfdna-tau 案例
- [parhat1/cfdna-tau-repository](https://github.com/parhat1/cfdna-tau-repository)（2026-05-30，★1）公开：LNN 用于 cfDNA 片段时常数癌症检测，**within-cohort AUC=0.91, 跨研究 LOSO AUC=0.40**。
- 价值：这是一个**坦诚的负向案例**——把 LNN 推到生物医学跨站点泛化场景时，分布偏移直接打回 0.4 量级。与 LNN 文献中常见的「OOB 鲁棒性」叙事形成直接张力。
- **复现价值**：
  - 数据集小（cfDNA 时序），单 GPU 即可复现。
  - LOSO 实验设计可作为我们 bench_suite 的「跨分布协议」样板。
  - 在 repo 的 README 中作者已经写了「Exploratory research」，文档诚实度+1。

### 5. 新增 CfC 工程化论文速览
- **MeloTune** ([arXiv:2604.10815v2], 2026-04-12)：iPhone 部署的 CfC + SVAF 生产级情感音乐策展，**不是研究 demo**——论文明确写到 "production system for affect-aware music curation with peer-to-peer mood coupling"。对 Jetson/RPi 复刻门槛高（涉及端到端音频管线），但 CfC 推理延迟数据值得抽取。

- **EEG-LNN 情感识别** ([2026-01-28])：作者自述「首个 EEG 上 LNN 全面应用」。与 EMG-Hand-Gesture 任务有结构相似性，可作为 round 74 后的备选研究对象。

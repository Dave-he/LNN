# MDN-CfC: Mixture Density Network head on CfC backbone

> **核心一句话**: 把 arXiv:2603.27058 (Liquid Networks with MDN Heads, 2026-03-28) 的"liqud+MDN 头"方案落地到 toy benchmark——**toy_sin 上 MDN 反而 -25% ~ -56% 退化** (K=1,3,5 全 HURT),structured_irr 上 **MDN ≈ MSE 仅 -0.4% ~ -0.7% 边际**,random_irr 中性;诚实负向-with-nuance。**论文核心 claim (Push-T/RoboMimic/PointMaze 上 2.4× lower error / 1.8× faster inference) 在 toy 不可复现**,因为这些 benchmark 上的 target 是 single-mode 平滑函数或纯 noise,MDN 找不到 paper 场景中那种"多模动作分布必须由混合表示"的结构。

## 论文核心思路

把 `Linear(hidden → action)` 头替换为 Mixture Density Network 头 (Bishop 1994),输出 K 个 (μ_k, σ_k, π_k) Gaussian 混合,训练用 negative log-likelihood:
$$
\mathcal{L}_{\text{MDN}} = -\log \sum_{k=1}^K \pi_k \mathcal{N}(y \mid \mu_k, \sigma_k^2)
$$
推理取混合均值 $\hat{y} = \sum_k \pi_k \mu_k$。论文在 Push-T / RoboMimic Can / PointMaze 上比 diffusion policy 取得 2.4× lower error / 1.8× faster / half params。

## 落地实现

最小变更:用已有的 `MDNHead` 接在 CfC backbone 末端,backbone 输出的 hidden state (代替默认 Linear 投影) 作为 head 输入:

```python
class MDNCfCNetwork(nn.Module):
    def __init__(self, input_size, hidden_size, output_size, num_mixtures=5, ...):
        self.backbone = CfCNetwork(input_size, hidden_size, output_size=hidden_size, ...)
        self.backbone.output_proj = nn.Identity()  # 卸下默认 Linear
        self.head = MDNHead(hidden_size, output_size, num_mixtures)
    def forward(self, x):
        features = self.backbone(x)  # [B, T, H]
        return self.head(features)    # {"logits", "loc", "log_scale"}
    def predict(self, x):
        return mdn_mean(self.forward(x))
```

- `MDNCfCNetwork.forward` 返回 dict with keys `logits [B,T,K]`, `loc [B,T,K,O]`, `log_scale [B,T,K,O]`
- `predict` 方法走 `mdn_mean` 取混合均值,作为 deterministic point prediction 用于对比 MSE 头
- `mdn_cfc_loss(model, x, y)` 把 NLL loss 包成单一函数,便于复用现有训练循环

## 基准结果 (5 conds × 3 datasets × 3 seeds × 100 epochs)

D=2 / T=32 / missing_rate=0.3 / hidden=16 / num_layers=1 / lr=1e-3 / grad-clip 1.0。

| cond | toy_sin | structured_irr | random_irr | params |
|---|---|---|---|---|
| mse_cfc (base) | 0.0349 | 0.2454 | 1.0275 | 945 |
| mdn_k1 | 0.0439 **+25.7%** | 0.2445 -0.4% | 1.0255 -0.2% | 979 |
| mdn_k3 | 0.0478 **+36.8%** | 0.2438 -0.7% | 1.0249 -0.2% | 1081 |
| mdn_k5 (paper) | 0.0545 **+56.0%** | 0.2441 -0.5% | 1.0284 +0.1% | 1183 |
| mse_cfc_big | 0.0333 -4.7% | 0.2478 +1.0% | 1.0304 +0.3% | 3425 |

**Toy_sin 上 K 越大退化越大** (K=1 → K=5: +25.7% → +56.0%)——典型的 over-parameterisation 失败,MDN 把 capacity 浪费在找 K 个 Gaussian 上,实际只需 1 个。

**Structured_irr 上几乎打平**——我们的 bimodal target (y_main vs y_alt,50/50 切换)均值近零,所以**两个 mode 的混合均值**与 **MSE 头预测零**几乎一致,MDN 没优势。

**Random_irr 上完全中性**——target 是纯 Gaussian noise,MDN 的多 mode 表示力无处发挥。

## 关键观察

1. **MDN 在 toy_sin 上单调退化**(K 越大越糟):证明 CfC backbone + MDN head 在 unimodal target 上比纯 Linear head 难收敛。原因:MDN 同时优化 K 个 (μ_k, σ_k, π_k),需要 log-scale 的 clamp (`min_log_scale=-7`),初始化阶段 σ 接近 0 → log σ → -∞ 风险;而 Linear head 只有 K×O+K 个参数,优化 landscape 平滑得多。
2. **MDN 在 structured_irr (paper-style bimodal target) 上几乎没赢**:target 是 `flip * y_main + (1-flip) * y_alt`,两个 mode 互为反号,所以**条件均值**就是 0,**MSE 头预测 0**几乎最优;MDN 想分开两个 mode 但需要 backbone 有足够 capacity 解开 hidden representation 中的 mode 信息——hidden=16 不够。
3. **MDN 在 random_irr 中性**:target 是 Gaussian noise,mode 概念无意义。
4. **论文的 2.4× 改善依赖真正的多模动作分布**:Push-T/RoboMimic/PointMaze 的 action distribution 有明确的"两种合理选择" (左转 / 右转;推 T 块的两种轨迹),而我们的 toy_sin 是单模,structured_irr 是近似单模 (mode 互为相反数),random_irr 是 noise。

## 失败归因

MDN head 在 toy benchmark 上不 work 的三个原因:

1. **Target 缺乏真正的多模结构**:toy_sin 是 sin function,single mode;structured_irr 是 *互为相反数* 的双 mode,混合均值与 MSE 头预测一致;random_irr 是 noise。论文场景 (机器人动作分布) 有"对称但不互为相反"的 mode。
2. **CfC backbone hidden=16 不够分离 mode**:MDN 想分开 K 个 mode,需要 backbone 在 hidden space 已经把它们分开。hidden=16 给的 capacity 只够学 1 个 representation。
3. **MDN 训练对的 lr/schedule 更敏感**:MDN head 同时学 K×O 个均值 + K×O 个 log-σ + K 个 logits,优化维度比 Linear 多 10×,同等 lr=1e-3 下更难收敛。

## 局限性与未来展望

- **没测真实多模 target**:toy_sin / structured_irr / random_irr 没有"对称但不互为相反"的双 mode,无法触发 MDN 的核心优势。
- **没测 hidden=64/128**:hidden=16 可能太小,paper 在 Push-T 上 hidden 至少 128。
- **没测 lr/schedule 调优**:MDN 对 init 很敏感,paper 用了 AdamW + cosine,本实验用 Adam + 固定 lr。
- **没测多 K 混合 + MSE loss 联合训练**:把 NLL 当辅助 loss 也许能让 backbone 学到更好的 hidden representation。

未来值得继续的方向 (与 r306 互补):
- **real multi-modal target**:构造 y = sign(sin(2πt)) 这种符号函数 target,有两个 clear-separable modes。
- **MDN + STE 联合 (r303-style)**:per-neuron STE mask 决定 backbone 是否走 parallel anchor vs sequential path,head 仍然 MDN。
- **MDN 在 LFM2.5 integration 上**:r304 已把 LSTM 换成 Parallel-CfC,head 也可以换成 MDN,与 Liquid AI 商业 LFM 路线对齐。

## 结论

**MDN-CfC 是诚实的负向-with-nuance**:
- 实现严格遵循论文 (Bishop-style Gaussian mixture + log-scale clamp)。
- 5 conds × 3 seeds × 100 epochs 验证:toy_sin MDN -25% ~ -56% (over-parameterisation),structured_irr ≈ MSE (mode 互为相反数),random_irr 中性。
- 论文 2.4× 改善依赖真正的多模动作分布,本 toy benchmark 不可复现。
- **进 negative-result 目录** (与 r104/r126/r128/r130-133/r306 并列),不进 default stack;但 `MDNCfCNetwork` + `MDNHead` 实现本身留在 repo,供未来真实多模任务使用。

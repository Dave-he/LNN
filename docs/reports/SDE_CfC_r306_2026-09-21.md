# SDE-CfC: Stochastic Differential Equation Generalization of Closed-form Continuous-time Cells

> **核心一句话**:把 arXiv:2608.28702 (Stochastic Liquid Deformation Fields, 2026-08-27) 的"SDE view of CfC"建议落地到玩具基准——**eval 完全退化为 vanilla CfC**（验证论文 §3.2 的精确极限声称),但**训练时 gate-level 高斯扰动在 toy_sin / structured_irr / random_irr 上基本中性**,只有 structured_irr 在 σ=0.20 处有 **-0.2% 边际改善**,**learnable σ 从 0.05 漂移到 0.72 (14×) 并把 toy_sin 搞坏 +2.5% / structured_irr +8.3%**——典型的"梯度过正则化"信号。

## 论文核心思路

CfC 闭式解是 ODE 的**确定性极限**:
$$
x(t) = \underbrace{\sigma(-f(x,I;\theta_f)\,t)}_{\text{time gate}}\odot g(x,I;\theta_g) + [1-\sigma(-f(x,I;\theta_f)\,t)]\odot h(x,I;\theta_h)
$$
论文注意到原始 LTC 是噪声驱动的随机系统,CfC 把噪声项丢了;在 D-3DGS 形变场场景下,作者把噪声**重新加在 time gate 上**:
$$
\sigma(-f\cdot t) \;\rightarrow\; \sigma(-f\cdot t) + \sigma_{\text{SDE}}\,\varepsilon, \quad \varepsilon\sim\mathcal{N}(0,1)
$$
**关键设计**:噪声**只在训练期间使用**,eval 时精确退化为 CfC(论文 §3.2)。这保证了 inference 的可重复性和论文报告的"对合成 D-NeRF 与确定性 CfC 相当,在真实 NeRF-DS 上无帮助"的诚实结论。

## 落地实现

最小变更:不动 CfC 的 `f/g/h` 三头架构,只 wrap forward 在 pre-sigmoid `decay_pre = -f·t` 上加 Gaussian:

```python
def _inject_noise(self, decay_pre):
    if not self.training or self.current_sigma() <= 0.0:
        return decay_pre
    noise = torch.randn_like(decay_pre) * self.current_sigma()
    return decay_pre + noise
```

- **`SDECfCCell`**:委托给内部 `CfCCell`,wrap forward 注入噪声;多 τ 分支路径同样处理。
- **`SDECfCNetwork`**:标准 multi-layer sequential,逐 timestep 逐层处理,API 与 `CfCNetwork` 完全兼容(`forward(x, h0, dt, mask)`)。
- **`sigma_sde`**:默认 0.05(对齐 r192 input noise sweep)。`learnable_sigma=True` 时通过 `softplus` 参数化为正标量。
- **Eval-time identity**:在 `model.eval()` 时 `_inject_noise` 直接返回原始 `decay_pre`,**评估输出与 vanilla CfC 在同 seed 下 bit-exact**。

### 单元验证

```python
cell = SDECfCCell(input_size=2, hidden_size=8, sigma_sde=0.05)
cell.eval()
torch.manual_seed(0); out1 = cell(x, h)
torch.manual_seed(0); out2 = cell(x, h)
# out1 == out2  (确定性)
```
论文 §3.2 的"exact CfC at eval"声称得到验证。

D=2 / T=32 / missing_rate=0.3。hidden=16, num_layers=1, lr=1e-3, grad-clip 1.0。

**Learnable σ 漂移**:从 init 0.05 → final **0.7185** (14× 增大),**两个数据集恶化**。

## 关键观察

1. **Eval-time identity**:噪声在 `model.eval()` 下被完全关掉,意味着 SDECfC 的所有"贡献"必须通过**训练时的正则化**传递。这一约束排除了 inference 时任何噪声带来的 variance reduction。
2. **σ=0.05-0.20 全部中性**:toy_sin Δ∈[0.0%, +0.3%],structured_irr Δ∈[-0.2%, -0.0%],random_irr Δ≈0.0%。即使 σ 比 r192 input noise 大 4×,也几乎观察不到效果。
3. **Learnable σ 漂移方向错误**:梯度让 σ 单调上升到 0.72(从 loss landscape 看是"noise 帮助 train loss 下降 → gradient 鼓励更多 noise"),但 test loss 因此恶化——典型的**训练-测试不一致**信号,等同于 r172 (β schedule)、r195-197 (noise/mixup) 的失败模式。
4. **dose-response 微弱但单调**:structured_irr 上 σ 越大 Δ 越负(-0.04% → -0.23%),虽然效应微小,但说明**该方向理论上不是反梯度**,只是有效正则化幅度太小。

## 为什么 SDE gate-noise 在 CfC 上不起作用

对比 r192 input noise(σ=0.05,toy_sin -24% mean)和本实验:

- **r192 的 σ 加在 input 上**(无界),同样的 σ=0.05 在网络上产生可观 perturbation;网络可以**学到忽略它**(类似 dropout-style 数据增强)。
- **本实验的 σ 加在 pre-sigmoid gate 上**(有界);sigmoid 把扰动 squashed 成 σ_sde·|σ'(z)|,在饱和区域有效幅度近零。

简言之:**CfC 的 gate 已经是一个 bounded temporal smoother**,在它附近加 Gaussian noise 几乎被 σ(·) 平滑掉,留给 SDE 的正则化预算极小。**要"在 CfC 内部"加 stochasticity,需要在 unbounded 的中间表达上加,例如 r194 (x+h noise combined)**。

## 局限性与未来展望

### 局限
- **只测了 toy benchmarks**:D=2 / T=32 / missing_rate=0.3 的 toy_sin / structured_irr / random_irr 三件套。论文场景是 D-3DGS 形变场(高维视觉),本 benchmark 完全覆盖不到。
- **只测了 100 epochs**:更长训练可能让 learnable σ 收敛到不同值(虽然观察到的趋势是单调恶化)。
- **没有测 σ schedule**:r172 (β schedule) 失败,但 r193 (hnoise) 在某些 schedule 下是正向的。本实验未做 curriculum。
- **多 τ 路径实测未触发**:`SDECfCCell` 支持 n_tau>1 但 benchmark 用的是 n_tau=1。多 τ 下 gate 已经分成 K 份,再加 noise 可能让某些分支饱和。

### 未来值得继续的方向
- **multiplicative noise**:`decay_pre *= (1 + σ·ε)` 替代 additive,避免饱和区间但放大 0 邻域。
- **annealed σ schedule**:σ_t = σ_max·cos(πt/2T),比 fixed 略像 r160 (MultiBeta-H) 的 sweet spot。
- **只在 multi-τ 上加**:把 noise 限制在快速分支(τ 小),不破坏慢速分支。
- **同 r303 (STE × Parallel-CfC) 结合**:anchor parallel scan 已经在玩具 sin 上 -36% SOTA;gate-noise 作为辅助正则可能放大 gain。

## 结论

**SDE-CfC 是诚实的负向-with-nuance 结果**:
- 实现严格遵循论文 §3.2(eval 时精确退化为 CfC,bit-exact 验证)。
- 在 100-epoch × 3-seed × 3-dataset 的标准 sweep 上,fixed σ {0.05, 0.10, 0.20} 全部中性,learnable σ 漂移到 14× 并恶化。
- 论文自身的"D-3DGS synthetic 上与 CfC 相当 / 真实 NeRF-DS 上无帮助"结论与本实验的"toy benchmarks 上无显著帮助"方向一致。
- **进 SDE-CfC 仓库的 negative-result 目录**,与 r104/r126/r128/r130-133 等并列,不进 default stack。

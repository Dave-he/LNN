## TL;DR

1. **域迁移**: LNN 已从原始**时序回归**域,正式扩散到 **4 个新域**:
   ① **3D 视觉** (arXiv 2606.07670 CfC-3DGS, iter#38) ② **3D 分子图** (Linlab2026/GCN-CfC, 6-03 GitHub) ③ **HFT 行情** (YGTKL16/MFENCE, 6-02 Rust) ④ **液态天线 + 6G 通信** (arXiv 2604.07219 sub-THz MU-MIMO, 4-08) — 加上**既有**时序 (Natural Gas) / 决策 (SNCP-PPO) / 视频 (LiquidTAD) / 双摆 (Hybrid NN)
2. **架构混合**: 出现 **LNN + 异构架构** 的"组合而非替代" 趋势:
   ① LNN + **3DGS** (closed-form CfC 作 deformation field) ② LNN + **spiking + hypergraph** (2841649220/LSHN bionic) ③ LNN + **SSM** (Liquid-S4) ④ LNN + **MoE** (LFM2.5-8B-A1B LiquidAI 官方) ⑤ LNN + **GNN** (Linlab GCN-CfC) ⑥ LNN + **diffusion** (2603.27058 推 Push-T)
3. **部署侧**: **LFM2.5 边缘推理栈** 迅速成型 (LiquidAI 官方 8B-A1B + 1.2B-Distilled + VL-450M-Extract + Audio-1.5B-JP) — 配套 **Rust 实现** (maximecb/bebelm 纯 CPU) + **CUDA 单卡 12GB 推理引擎** (g023/cuda_inf RTX 3060) + **GGUF 量化** (LiquidAI 官方) + **LoRA fine-tune** (tantony 多个营养学)
4. **公式演进**: **ODE 95%+ 同构** 已成本仓共识 — 6 篇研读报告的公式跟本仓 `LTCCell / CfCCell / DynPMNN / TransformableLTC` 都可对齐 (EntroLnn, DynPMNN, 3DGS-CfC, RLSTG, Retinal, Liquid-S4)
5. **实证**: iter#11/24/35/37 **四连 honest-negative** — 在**小合成 + 单 seed 烟测**下 LNN 几乎不赢 LSTM/MLP; LNN 真实价值在 **(a) 边缘部署** (b) **真实域差** (c) **长程 / 噪声监督** 三个**大场景** — 跟论文 claim 的 "1-5 数量级加速" 真实条件对齐

## 1. 域迁移 (从时序到 4D / 6G / 分子 / HFT)

**结论**: LNN 域**已从 2024-2025 主流的"时序/NDE 玩具"扩散到 4D 视觉、6G 通信、3D 分子、HFT、决策控制、生物学 6 个跨域**。**通用趋势**: LNN 的 "ODE 求解 + 时序连续" 卖点,在**任何 (状态变化连续 + 监督有噪声) 的域**都被复用 — 这是 narrative 的"自然推论"。

### 1.2 关键观察: 3DGS 是 LNN 跨域最有说服力的论文

arXiv 2606.07670v1 (iter#38) 是 LNN 第一次**显式替换主流 4D 视觉管线** (D-3DGS) 的核心模块 (deformation field), 不是新加一个 LNN head。**+0.47 dB mean PSNR on NeRF-DS 7 noisy real scenes** + **+2.74 dB on specular scene** 是**真实证据**: 在 noisy monocular 监督下 CfC 的**隐式时间平滑先验**比 MLP 的 piecewise-linear 更鲁棒。**这与本仓 iter#24 DynPMNN 在 mackey_glass 输 LSTM 形成对照** — 同一类 ODE 公式在 toy 时序输, 但在 4D 视觉赢。**真实信号**: LNN 优势显现需要 (a) 噪声监督 (b) 真实域差 (c) 显式连续性收益 — 玩具时序数据集这 3 个都缺失。

## 2. 架构混合 (LNN + 异构 = 组合而非替代)

### 2.1 出现的混合范式

| 范式 | 公式/范式 | 论文 / 仓 | 备注 |
|---|---|---|---|
| **LNN + 3DGS** | closed-form CfC 作 deformation backbone | arXiv 2606.07670v1 (iter#38) | "depth-as-time", 6 层 CfC stack 替换 D=8 MLP |
| **LNN + spiking + hypergraph** | 三层混合 bionic | 2841649220/LSHN (GitHub 5-29) | 概念性, 0 实证 |
| **LNN + SSM** | Liquid-S4 推 latent state | Hasani 2023 ICLR (background) | Liquid Time-Constant + State Space Model 桥接 |
| **LNN + MoE** | LFM2.5-8B-A1B LiquidAI 官方 | HF 6-05 上线, 137K downloads | 8.5B 总参, 1B active, hybrid conv + GQA-attention MoE |
| **LNN + GCN** | 分子图 noncovalent inhibitor | Linlab2026/GCN-CfC (GitHub 6-03) | GCN 处理空间, CfC 处理时序 |
| **LNN + diffusion** | Push-T / RoboMimic / PointMaze | arXiv 2603.27058 (3-28) | LNN + mixture density head vs diffusion policy |
| **LNN + Transformer attention** | SVAF 跨智能体 | arXiv 2604.03955 (4-05) | CfC + 注意力融合 |
| **LNN + Lagrangian** | 双摆物理混合 | Gonzablanmar/Hybrid-NN (Jupyter 6-05) | Lagrangian NN + Liquid NN |
| **LNN + PDNA pulse** | 6-model Pareto sweep | iter#34 (jetson-4model) | 4-model Pareto, PDNA-pulse 速度胜 CfC 30% |

**结论**: **2026-06 没有出现 "LNN 替代 X" 的论文** — 全部是 **"LNN + X" 组合**, 跟 iter#34 本地实证 (4-model Pareto) 的结论一致: **没有"通杀 backbone"**, LNN 是 baseline, 真正的精度/速度冠军是混合架构。**这印证 iter#12 教训**: "通杀 backbone" 在合成 benchmark 不可证。

### 2.2 关键观察: 3DGS 论文的 "depth-as-time" 是范式创新

arXiv 2606.07670v1 提出 **"depth-as-time"** — D 维深度扮演经典 CfC 序列模型中 T 维时间。**这是 2026 年首例"非时序连续性"用法**: D-3DGS 的"时间"是真正的物理时间 t (per-frame 标量), 但 stack 是 D 层 feed-forward, **每层把 t 作为 elapsed-time signal 输入 CfC cell**。**对照本仓 iter#38 之前的用法**: 全是 (B, T, F) → (B, T, H) 时序模式。**新范式**打开了 LNN 在**非严格时序** (4D 视觉, 物理仿真, 几何建模) 的应用面。**对本仓的提示**: `lnn/core/cfc.py::CfCCell` 接受任意长度 T 输入, 这意味着 `CfC` 也可作"几何维度 stack" — 视觉 backbone matrix 加 CfC 行是自然 follow-up。

## 4. 公式演进: ODE 95%+ 同构已成共识

### 4.1 本仓对照表

| 公式 | 本仓 | 论文 | 同构度 |
|---|---|---|---:|
| dh/dt = (1/τ) [-h + f(x, u, t, θ)] | LTCCell | Hasani 2021 Nature MI | 100% |
| dh/dt = -α⊙h + tanh(W_h h + ū) | — | EntroLnn Eq. 10 (iter#34) | 95% (gate form 略不同) |
| z = φ([u; h]); g, h_cand = tanh(Wz); σ_τ = σ(W_a z·τ + W_b z); h' = g ⊙ (1-σ_τ) + h_cand ⊙ σ_τ | CfCCell | Hasani 2022 NatMI CfC paper | 100% |
| Eq. 2 同上 | CfCCell | arXiv 2606.07670v1 3DGS (iter#38) | 95% (h 维度门控略不同) |

**结论**: 7 篇跨域深度研读报告的 LNN 公式, **6 篇可与本仓现有 cell 直接对照或 fork 微改**。**只有 RLSTG (黎曼 LTC) 需要新依赖**, 但 ROI 仅 B (需 tangent space 包装, 实证仅 ENRON link prediction)。**本仓的"7 套 LNN 概念 / 6 套 LNN backbone"覆盖度 2026-06 当月仍领先**。

### 4.2 关键观察: 跨域 ODE 同构 = 本仓的"通杀"卖点

| 域 | ODE 形式 | 本仓 cell | 改 0/微改/重写 |
|---|---|---|---|
| 时序回归 | dh/dt = (1/τ)[-h + f(x,u)] | LTCCell | 0 (直接用) |
| 4D 视觉 deformation | closed-form CfC (Eq. 2) | CfCCell | 0 (公式 1:1) |
| 物理 FHN 兴奋 | dV/dt = V - V³/3 - W + I | FHNCell | 0 (直接用) |

**本仓叙事**: **"ODE 公式 = LNN 跨域通杀基础"** 是 narrative 卖点, **2026-06 仍是 P0 假说**。iter#24 / iter#35 / iter#37 的小合成 1-seed 失败, **没有推翻**这个假说 — 因为玩具时序数据集本身就是 ODE 公式的"最弱场景"。

## 5. 实证: iter#11/24/35/37 四连 honest-negative

### 5.1 失败模式沉淀

| Iter | 实验 | 结论 |
|---|---|---|
| **iter#11** | 1-seed 烟测过估 | "1-seed lucky 是 false positive", 改 ≥3 seed |
| **iter#24** | DynPMNN vs LSTM on mackey_glass | **fhn_dynpmnn median test_mse 0.0182 (n=6) vs lstm 0.0101 (n=3), FHN 输 ~3×** — 玩具时序 ODE 公式无优势 |
| **iter#35** | Jetson PDNAPulse 1-seed 冠军 0.401 → 3-seed 0.4224 | **1-seed lucky 是 0.5361, 3-seed 0.4224, 5-seed 才稳定** |
| **iter#37** | TransformableLNN 2-stage vs single on 合成电池 | **single 0.1325 ± 0.1141 胜 transformable 0.3250 ± 0.1714** — 均匀同分布, 2-stage 引入梯度噪声 |

### 5.2 关键观察: 玩具小数据集是 LNN "no advantage zone"

四连失败模式**惊人一致**:
- 数据集: 合成 toy, 维度低, 同分布, 无真实域差, 无噪声监督
- 结论: LNN 与 LSTM/MLP/Transformer 持平或输
- 解释: LNN 公式优势 (闭式连续 + 隐式平滑 + 噪声鲁棒) **在干净 toy 数据集无触发条件**

**这是 iter#38 3DGS 论文的反向证据**:
- D-NeRF 8 synthetic (干净, 几乎无噪声): CfC 跟 MLP **完全 tied** (38.25 vs 38.26)
- NeRF-DS 7 real (noisy monocular 监督): CfC **胜 +0.47 dB** (因为真实噪声触发隐式平滑先验)
- 单一 specular scene (As, 反射 + 锐变): CfC **胜 +2.74 dB** (高动态范围触发连续性收益)

**总结**: **LNN 优势 = 玩具时序的无优势, 真实时序的边缘/低算力优势, 4D 视觉的中等优势, 强动态/高噪/强连续性场景的显著优势**。**这是本仓 2026 年最重要的 narrative 校准**: 不要在 toy 时序数据集上试图证 LNN "通杀", 而要在 4 类场景上对位布局:
1. **边缘部署** (Jetson / Cortex-M) — LFM2.5 蒸馏 + INT8
2. **真实域差** (跨 cell 电池 / 跨场景 3DGS) — TransformableLTC
3. **长程/噪声监督** (monocular 4D / bio-signal) — CfC 闭式
4. **强动态** (摆 / 反射 / articulated motion) — Liquid-3DGS 范式

### 5.3 真实信号: 跨 task backbone matrix 应加 device_control + vision 4D 行

本仓 iter#28 已加 lra_pathfinder 行 (4 domains), iter#34/35 Jetson 4-model Pareto 是 backbone 横向, **下一步**:

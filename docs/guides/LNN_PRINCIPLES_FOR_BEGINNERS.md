# LNN 原理入门：给高中生的液态神经网络指南

这份文档回答四个问题：

1. 液态神经网络为什么会出现，它和普通神经网络有什么不同。
2. 核心公式从哪里来，怎样一步步推到 LTC 和 CfC。
3. 一个 LNN 模型怎样训练。
4. 训练好的模型怎样部署到电脑、Jetson 或更小的边缘设备上。

目标读者是刚学过函数、斜率、指数函数的高中生。遇到公式时，可以先看公式下面的中文解释，再回头看符号。

## 1. 先用一句话理解 LNN

普通神经网络像一张固定电路图：输入进来，经过一层层计算，输出结果。

液态神经网络像一杯会晃动的水：它不仅看当前输入，还保留一个会随时间连续变化的内部状态。新的输入会改变这杯水的流动速度、衰减速度和记忆方式，所以它更适合传感器、机器人、控制系统、医疗监测、金融时序这类“时间一直在走”的问题。

这里的“液态”不是说权重每一秒都全部换掉，而是说模型的有效动力学会跟着输入和状态改变。例如同一个神经元看到平稳信号时可以慢慢变化，看到突发信号时可以快速响应。

## 2. 背景知识

### 2.1 什么是时间序列

时间序列就是按时间排好的一串数据：

```text
时间:   t0    t1    t2    t3    ...
温度:  21.1  21.3  22.0  21.8  ...
速度:   0.2   0.4   0.9   1.1  ...
```

很多真实数据不是“单张图片”，而是“连续过程”：无人车的摄像头、机器人的关节角度、心率、股票价格、网络流量。模型需要记住过去，也要适应当前变化。

### 2.2 什么是隐藏状态

隐藏状态可以理解为模型的“短期记忆”。记作：

$$
h_t
$$

其中 $t$ 表示时间，$h_t$ 表示模型在时间 $t$ 时刻的内部记忆。

如果模型看到输入 $x_t$，并更新自己的记忆，普通 RNN 常写成：

$$
h_t = \tanh(W_x x_t + W_h h_{t-1} + b)
$$

中文解释：

- $x_t$：当前输入。
- $h_{t-1}$：上一时刻的记忆。
- $W_x, W_h, b$：模型要学习的参数。
- $\tanh$：把数值压到 $-1$ 到 $1$ 附近，避免无限变大。

这类写法把时间看成一格一格的离散台阶：第 1 秒、第 2 秒、第 3 秒。但真实世界经常不是这样，传感器可能 0.1 秒来一次，也可能 0.7 秒才来一次。

### 2.3 什么是微分方程

微分方程描述“一个量变化得有多快”。最简单的写法是：

$$
\frac{dh}{dt} = f(h, x, t)
$$

左边 $\frac{dh}{dt}$ 表示 $h$ 随时间变化的速度，也就是斜率。右边 $f$ 表示这个变化速度由当前状态 $h$、输入 $x$ 和时间 $t$ 决定。

一个生活例子：水杯里有热水，放在冷空气中会逐渐变冷。温度越高，降温越快；接近室温后，变化变慢。这就是一个连续变化过程。

LNN 的核心想法就是：把神经网络的隐藏状态也当作一个连续变化的物理量。

## 3. 从普通神经元推到 LNN

### 3.1 普通神经元

一个最简单的神经元可以写成：

$$
y = \sigma(wx + b)
$$

中文解释：

- $x$：输入。
- $w$：输入的重要程度。
- $b$：偏置，用来平移结果。
- $\sigma$：激活函数，让模型能表达非线性关系。
- $y$：输出。

它的问题是：这个公式没有“时间”。输入一来就输出，不能自然描述“慢慢变化”“逐渐忘记”“等待一段时间再反应”。

### 3.2 加入记忆：RNN

RNN 加入上一时刻的隐藏状态：

$$
h_t = \tanh(W_x x_t + W_h h_{t-1} + b)
$$

这已经有了记忆，但它仍然默认每一步间隔差不多。如果传感器时间间隔不规则，就需要额外处理。

### 3.3 加入连续时间：基础 LNN

LNN 把“下一步怎么变”改成“现在变化速度是多少”：

$$
\frac{dh(t)}{dt} = F_\theta(h(t), x(t), t)
$$

其中 $F_\theta$ 是一个带参数的神经网络。训练时，模型学习参数 $\theta$，让这条连续变化曲线更符合数据。

这一步很重要：模型不再只会按固定台阶跳，而是能在任意时间间隔 $\Delta t$ 上演化。

## 4. LTC 的公式和推导

LTC 是 Liquid Time-Constant Network，意思是“液态时间常数网络”。

### 4.1 先看一个会漏水的桶

假设桶里水位是 $h$。没有新水流入时，水会从洞里漏掉：

$$
\frac{dh}{dt} = -\frac{1}{\tau}h
$$

中文解释：

- $h$ 越大，漏得越快。
- $\tau$ 叫时间常数。$\tau$ 大，漏得慢，记忆久；$\tau$ 小，漏得快，反应快。
- 负号表示水位下降。

如果有外部输入 $u$ 往桶里加水：

$$
\frac{dh}{dt} = -\frac{1}{\tau}h + u
$$

这已经像一个神经元了：旧记忆会衰减，新输入会推动状态变化。

### 4.2 用高中斜率近似做一步更新

微分方程说的是瞬时变化速度。计算机不能真正连续地算，只能用小步近似。若步长是 $\Delta t$：

$$
h_{t+\Delta t} \approx h_t + \Delta t \cdot \frac{dh}{dt}
$$

代入漏水桶公式：

$$
h_{t+\Delta t}
\approx h_t + \Delta t \left(-\frac{1}{\tau}h_t + u_t\right)
$$

这就是 Euler 更新。它的意思是：新水位等于旧水位，加上“这一小段时间里的变化量”。

### 4.3 LTC 让时间常数也由网络学习

普通漏水桶的 $\tau$ 是固定的。LTC 的关键是：让有效时间常数根据当前输入和状态改变。

本仓库 `lnn/core/ltc.py` 中的简化 LTC 动力学可理解为：

$$
\frac{dh}{dt}
= -\frac{h}{\tau_{\mathrm{eff}}(h, x)} + A \odot b_\theta(h, x)
$$

并且：

$$
\tau_{\mathrm{eff}}(h, x)
= |\tau_{\mathrm{base}}| + f_\theta(h, x) + \epsilon
$$

中文解释：

- $h$：当前隐藏状态。
- $x$：当前输入。
- $\tau_{\mathrm{eff}}$：有效时间常数，不再固定，而是由输入和状态决定。
- $f_\theta(h, x)$：神经网络算出的门控值，控制响应速度。
- $b_\theta(h, x)$：神经网络算出的候选推动方向。
- $A$：可学习的缩放参数。
- $\odot$：逐元素相乘，可以理解为每个隐藏单元各算各的。
- $\epsilon$：很小的正数，防止除以 0。

直觉：LTC 给每个神经元装了一个可调节的“漏水孔”。遇到快速变化的信号，孔可以变大，模型快速更新；遇到平稳信号，孔可以变小，模型保留记忆。

### 4.4 LTC 为什么训练和推理更慢

LTC 需要求解微分方程。常见方法包括 Euler、RK4、dopri5。步数越多，结果越精细，但计算越慢。

所以 LTC 的优点是连续时间解释更强，缺点是工程成本更高。

## 5. CfC 的公式和推导

CfC 是 Closed-form Continuous-time，意思是“闭式连续时间网络”。它的目标是保留连续时间思想，但避免每一步都跑 ODE solver。

### 5.1 从一个可精确求解的方程开始

看一个简单方程：

$$
\frac{dh}{dt} = -\lambda(h - g)
$$

中文解释：

- $g$ 是目标状态。
- $h$ 会朝 $g$ 靠近。
- $\lambda$ 控制靠近速度。$\lambda$ 越大，靠近越快。

这个方程有解析解：

$$
h(t+\Delta t)
= e^{-\lambda \Delta t} h(t)
+ \left(1 - e^{-\lambda \Delta t}\right) g
$$

中文解释：

- $e^{-\lambda \Delta t}$ 是“还保留多少旧记忆”。
- $1 - e^{-\lambda \Delta t}$ 是“吸收多少新目标”。
- 时间间隔 $\Delta t$ 越大，旧记忆保留越少。

### 5.2 CfC 把解析解变成可学习的门控混合

真实任务里，目标 $g$ 和速度 $\lambda$ 不会提前知道，所以 CfC 用神经网络学习它们。

本仓库 `lnn/core/cfc.py` 中的 CfC 单元可概括为：

$$
z = [x_t, h_t]
$$

$$
f = \sigma(W_f z + b_f)
$$

$$
g = \tanh(W_g z + b_g), \quad r = \tanh(W_r z + b_r)
$$

$$
d = \sigma(-f \odot s \odot \Delta t)
$$

$$
h_{t+\Delta t} = d \odot g + (1-d) \odot r
$$

中文解释：

- $z$：把当前输入和旧记忆拼起来。
- $f$：学出来的时间门控，决定变化速度。
- $s$：可学习的时间缩放参数。
- $d$：混合比例，和时间间隔 $\Delta t$ 有关。
- $g, r$：两个候选状态分支。
- 最后一行表示：新隐藏状态是两个候选分支的加权混合。

注意：论文中的 CfC 有更完整的变体；本仓库实现的是工程上清晰、可测试的 CfC 风格闭式更新。它的关键思想是：用可学习门控近似连续时间解，省掉显式 ODE 求解。

### 5.3 CfC 为什么适合工程部署

CfC 不需要数值积分器。每个时间步主要是线性层、激活函数和逐元素乘法，所以通常比 LTC 快，更容易部署到 CPU、Jetson、移动端和实时系统。

## 6. LNN、LSTM、Transformer 的区别

| 模型 | 怎么记忆 | 怎么处理时间 | 适合场景 | 主要代价 |
|---|---|---|---|---|
| RNN/LSTM/GRU | 离散隐藏状态 | 默认一步一步跳 | 一般时间序列 | 对不规则时间要额外处理 |
| Transformer | 注意力看全局上下文 | 通常靠位置编码 | 文本、图像、多模态大数据 | 参数和显存需求大 |
| LTC | ODE 连续状态 | 直接建模 $\Delta t$ | 物理系统、控制、可解释时序 | ODE 求解较慢 |
| CfC | 闭式连续时间更新 | 门控混合时间影响 | 边缘部署、快速时序建模 | 解释性弱于完整 ODE |

## 7. LNN 怎样训练

训练可以理解为“反复试错，调参数，让预测越来越准”。

### 7.1 数据准备

典型数据形状是：

```text
x: [batch, time, features]
y: [batch, output]
```

例子：

- `batch`：一次训练多少条样本。
- `time`：每条样本包含多少个时间点。
- `features`：每个时间点有多少个传感器特征。
- `y`：要预测的目标，比如下一秒速度、未来温度、控制动作。

如果时间间隔不固定，还应提供：

```text
dt:   [batch, time, 1]       # 相邻观测之间隔了多久
mask: [batch, time, features] # 哪些值是真实观测，哪些缺失
```

### 7.2 前向传播

模型从第一个时间点走到最后一个时间点：

```text
输入序列 -> LNN hidden state 连续更新 -> 输出预测
```

在代码中就是：

```python
import torch
from lnn import CfCNetwork

x = torch.randn(32, 50, 3)
dt = torch.ones(32, 50, 1)
mask = torch.ones(32, 50, 3)

model = CfCNetwork(input_size=3, hidden_size=32, output_size=1, return_sequences=False)
y_pred = model(x, dt=dt, mask=mask)
```

### 7.3 损失函数

如果是回归任务，常用均方误差：

$$
\mathrm{MSE}
= \frac{1}{N}\sum_{i=1}^{N}(\hat{y}_i - y_i)^2
$$

中文解释：

- $\hat{y}_i$：模型预测值。
- $y_i$：真实答案。
- 差距越大，平方后惩罚越大。
- 训练目标就是让 MSE 变小。

### 7.4 反向传播

神经网络训练的核心是：

1. 先预测。
2. 算误差。
3. 根据误差反推每个参数应该增大还是减小。
4. 用优化器更新参数。

更新公式可以写成：

$$
\theta \leftarrow \theta - \eta \nabla_\theta \mathcal{L}
$$

中文解释：

- $\theta$：所有可学习参数。
- $\eta$：学习率，表示每次迈多大步。
- $\mathcal{L}$：损失函数。
- $\nabla_\theta \mathcal{L}$：损失对参数的斜率，告诉我们往哪里改。

LTC 的 ODE solver 和 CfC 的门控更新都可以放进 PyTorch 自动求导系统里，所以仍然可以用常规反向传播训练。

### 7.5 实用训练流程

一条稳妥流程：

1. 切分数据：训练集、验证集、测试集按时间或场景分开，避免泄漏。
2. 标准化：让每个特征均值接近 0、方差接近 1。
3. 先跑小模型：例如 `hidden_size=16` 或 `32`。
4. 先选 CfC：速度快，方便定位数据和训练问题。
5. 再试 LTC：需要更强连续时间解释或物理一致性时再上。
6. 记录多 seed：至少 3 个随机种子，避免单次幸运结果。
7. 看验证集：验证集变差时早停，不要只看训练集。
8. 最后只用测试集做一次诚实评估。

本仓库常用命令：

```bash
python -m pytest tests -q -m "not large_budget"
python scripts/ablation_lnn_vs_lstm_timeseries.py --dataset mackey_glass --seeds 0,1,2
python scripts/jetson_lnn_benchmark.py --quick
```

## 8. 训练时常见问题

| 问题 | 可能原因 | 处理方式 |
|---|---|---|
| 训练集很好，测试集很差 | 过拟合或数据泄漏 | 按时间/场景切分，增加验证集，降低模型规模 |
| LTC 很慢 | ODE solver 步数多 | 先用 CfC，或用 Euler/RK4 小步数 smoke test |
| 不规则时间效果差 | 没有传 `dt` 或单位混乱 | 统一秒/毫秒单位，把 `dt` 输入模型 |
| 缺失值导致 NaN | 缺失没有 mask | 用 `mask` 标记缺失，并把 NaN 替换为 0 |
| 单次结果很亮眼 | 随机种子幸运 | 跑多 seed，报告均值、方差、中位数 |
| 边缘端太慢 | 模型太大或 solver 太重 | 用 CfC、减小 hidden size、减少层数、量化 |

## 9. LNN 怎样部署

部署就是把训练好的模型放到真实设备上稳定运行。

### 9.1 选择模型

| 场景 | 优先选择 | 理由 |
|---|---|---|
| 快速基线、CPU 实时推理 | CfC | 不需要 ODE solver，速度快 |
| 物理系统、需要解释时间常数 | LTC | 时间常数更直观 |
| 极小设备或微控制器风格 | Euler-LTC-DT / 小 CfC | 算子简单，内存低 |
| 有缺失、不规则采样 | CfC with `dt`/`mask` | 工程实现直接支持 |
| Jetson smoke benchmark | CfC/GRU/LTC 对照 | 先验证延迟和吞吐 |
| 噪声很强的多模态数据 | Noise-adaptive CfC 类模型 | 可以学习降低噪声流影响 |

### 9.2 部署前检查清单

1. 固定输入格式：窗口长度、特征顺序、单位、`dt` 单位都写清楚。
2. 保存标准化参数：训练时的均值和方差必须随模型一起部署。
3. 固定模型版本：记录 git commit、配置文件、训练数据版本。
4. 测延迟：单条样本延迟、批量吞吐、最大内存占用都要测。
5. 测边界情况：全 0、极大值、缺失值、长时间无输入。
6. 准备回退策略：模型输出异常时使用规则控制器或旧模型。
7. 监控漂移：真实数据分布变了，要触发重新评估或再训练。

### 9.3 Jetson / 边缘设备建议

1. 先用 CPU 跑通，再切 CUDA。
2. 优先用 `hidden_size=16/32/64`，不要一开始就堆大模型。
3. 先跑 batch=1 的真实延迟，再跑大 batch 吞吐。
4. CfC 优先于 LTC，因为少了 ODE solver。
5. 如果要用 LTC，先用 Euler 或固定步数 RK4，避免动态 solver 带来不可控延迟。
6. 尝试 `torch.no_grad()`、`model.eval()`、半精度或量化，但每一步都要重新核对误差。

示例推理代码：

```python
import torch
from lnn import CfCNetwork

model = CfCNetwork(3, 32, 1, return_sequences=False)
model.eval()

with torch.no_grad():
    x = torch.randn(1, 32, 3)
    dt = torch.ones(1, 32, 1)
    mask = torch.ones(1, 32, 3)
    y = model(x, dt=dt, mask=mask)
```

## 11. 一页总结

LNN 可以理解为“带连续时间记忆的神经网络”。普通 RNN 每一步跳一次，LNN 用微分方程描述隐藏状态怎样随时间流动。LTC 让时间常数随输入改变，像可调漏水孔；CfC 用闭式门控混合近似连续时间解，省掉 ODE solver，工程上更快。

训练 LNN 和训练普通神经网络一样：准备序列数据，前向传播，算损失，反向传播，验证和测试。部署时重点不是追求最大模型，而是固定输入格式、控制延迟、处理缺失和不规则时间、记录版本，并在真实设备上测稳定性。

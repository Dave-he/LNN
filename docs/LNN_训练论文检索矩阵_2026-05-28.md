# LNN 训练论文检索矩阵 - 2026-05-28

本文件补齐“如何训练 LNN”专题的可审计检索链路：先记录检索范围和候选论文，再按方向沉淀到各可行报告。原始候选来自 [[papers/daily/2026-05-28_lnn_research.json]]，本次人工筛选结果见 [[papers/daily/2026-05-28_lnn_training_methods_search.json]]。

## 1. 检索范围

检索问题：

1. LNN/CfC/LTC/NCP 如何训练、如何处理 `dt`、solver、梯度和稳定性。
2. 不同任务如何构建数据集，包括滑窗时间序列、医疗不规则序列、机器人 episode、动态图、视频片段和物理多模态观测。
3. 各方向应采用什么架构组合，例如 CfC、LTC、AutoNCP、GNN+LNN、Liquid-S4、LiquidTAD、LTC+physics loss。
4. 如何优化和调参，包括 `seq_len`、`hidden_size`、`tau/dt`、ODE solver、稀疏接线、蒸馏、量化、OOD 切分和闭环评估。

检索源：

- arXiv / arXiv API：LNN、LTC、CfC、NCP、Liquid-S4、LiquidTAD、Graph/Telecom/Physics 方向论文。
- Nature Machine Intelligence：CfC 与 NCP 核心论文。
- 官方文档或数据源：`ncps`、PhysioNet 2012、UCI HAR、RoboMimic、Minari、Liquid AI / Hugging Face。
- 本仓库每日追踪：[[docs/daily/2026-05-28_LNN_research_digest]]。

## 6. 总结

当前最可落地路线是：先用 CfC 做时间序列基线，再补 `dt/mask` 支持；第二阶段推进 AutoNCP/MDN 控制和 Jetson Pareto benchmark；第三阶段再做 GNN+LNN、Liquid-S4/LiquidTAD 和 physics-informed LTC。每个方向的报告都已经给出数据格式、架构搭建、训练配置、优化项和落地建议。
